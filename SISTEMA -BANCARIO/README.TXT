 Sistema Bancário em Node.js

Sobre o projeto
Este projeto consiste em um sistema bancário desenvolvido em JavaScript utilizando Node.js. O sistema permite realizar operações básicas de gerenciamento de contas e movimentações financeiras por meio do terminal.
Funcionalidades

·	Criar conta bancária.
·	Realizar depósitos.
·	Realizar saques.
·	Listar contas cadastradas.
·	Listar movimentações financeiras.
·	Encerrar o sistema.
 Tecnologias utilizadas
·	JavaScript
·	Node.js
·	readline-sync

*** Como executar o projeto

1. Clone o repositório
bash
git clone URL_DO_SEU_REPOSITORIO


2. Entre na pasta do projeto
bash
cd SISTEMA-BANCARIO

3. Instale as dependências
bash
npm install

Ou instale diretamente:

bash
npm install readline-sync

4. Execute o sistema
bash
node VENDAS.JS
